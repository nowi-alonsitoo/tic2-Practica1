Etiqueta Significado
td Define una celda normal, es decir, una celda que contiene información o datos de la tabla.
tr Define una fila horizontal dentro de la tabla (table row). Dentro de ella se colocan las celdas con td y th
th Diseño CSSDefine una celda que sirve como encabezado para una columna o una fila. Por defecto, los navegadores suelen mostrar su contenido en negrita y centrado.
table Es la etiqueta principal. Sirve para crear una tabla en HTML y contiene el resto de las etiquetas que forman sus filas y celdas.
caption Añade un título o una descripción breve a la tabla. Se coloca justo después de abrir la etiqueta table
thead Agrupa las filas que contienen los encabezados de la tabla (table head). Normalmente incluye los nombres de las columnas y suele contener elementos tr con celdas th
tbody Agrupa las filas que contienen los datos principales de la tabla. Normalmente incluye filas tr con celdas td
